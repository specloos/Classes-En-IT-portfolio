# Lesson 02 · English for AI tools (A2–B1)

> MUESTRA: lección de ejemplo creada para revisar y adaptar. Usa el documento `vocabulario_tecnico_EN_ES.docx` como apoyo.

**Level:** A2–B1 · **Duration:** 60 min · **Audience:** adults who use ChatGPT, Gemini or Copilot

## Objectives
- Recognise 15 interface words: *upload, attach, regenerate, settings, sources…*
- Write a simple prompt in English.
- Understand basic instructions in an AI tool.

## 1. Warm-up (5 min)
Which AI tools do you use? Is the interface in English or Spanish?

## 2. Vocabulary match (15 min)
| English | Español |
|---|---|
| Upload | a. Regenerar |
| Regenerate | b. Fuentes |
| Settings | c. Subir |
| Sources | d. Borrador |
| Draft | e. Configuración |

## 3. Imperatives in prompts (15 min)
Prompts often use the imperative: **Summarise** this text. **Write** an email. **List** five ideas.
Turn these into prompts:
1. (resumir / el documento / 3 frases)
2. (escribir / correo / proveedor / formal)
3. (traducir / texto / al español)

## 4. Production (20 min)
Write three prompts in English for tasks from your job. Test them in Gemini or ChatGPT and compare the answers with a partner.

## 5. Wrap-up (5 min)
Which three new words will you use this week?

## Answer key
Upload → c · Regenerate → a · Settings → e · Sources → b · Draft → d
1. Summarise the document in three sentences.
2. Write a formal email to a supplier.
3. Translate this text into Spanish.
